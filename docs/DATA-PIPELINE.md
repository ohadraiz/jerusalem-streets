# פייפליין הנתונים — מה נמדד ומה הוחלט

מסמך זה מתעד בדיקות בפועל (לא הערכות) ואת ההחלטות שנגזרו מהן. תאריך: 2026-10-21.

## השאלה

להביא את כל הרחובות בירושלים, מקובצים לפי שכונה, עם קואורדינטות — בלי להמציא נתונים ובלי תלות בשירות בתשלום.

## מקורות שנבדקו

| מקור | בקשה | תוצאה | מסקנה |
|---|---|---|---|
| GovMap — האתר | `GET https://www.govmap.gov.il/` | **403** (CloudFront, גוף חסימה) | חסום לבקשות שרת |
| GovMap — חיפוש | `GET https://es.govmap.gov.il/TldSearch/api/DetailsByQuery?...` | **fetch failed** | לא נגיש מהסביבה הזו |
| GovMap — API | `GET https://www.govmap.gov.il/api/layers/` | **403** | דורש מפתח/הרשאה; לא שמיש כאן |
| data.gov.il | `package_search?q=רחובות ירושלים` | **200**, `count: 0` | אין מאגר תואם בשאילתה הזו |
| OSM / Overpass | `way(area)["highway"]["name"]` | **200**, `ways: 9828` | PASS מקור העבודה |

**החלטה 1:** GovMap לא ישמש כמקור נתונים. הוא נשאר אופציה לקישור deep-link למשתמש, לא לפייפליין.
**החלטה 2:** OSM/Overpass הוא המקור. רישיון ODbL — חובה ייחוס "© OpenStreetMap contributors" במסך.

### זיהוי השטח

`area["name"="ירושלים"]["admin_level"="8"]` החזיר **0** דרכים — השטח לא זוהה.
`area["name:he"="ירושלים"]["boundary"="administrative"]` החזיר **9,828** דרכים עם `highway` ו-`name`.
**החלטה 3:** תמיד לזהות שטח לפי `name:he` + `boundary=administrative`, לא לפי `name` או `admin_level` בלבד.

## שיוך רחוב לשכונה — המדידה ששינתה את התוכנית

| בדיקה | תוצאה | משמעות |
|---|---|---|
| דרכים עם `addr:suburb` | **0** | תג שכונה לא קיים בנתונים — אפס תועלת |
| דרכים עם `addr:city` | **6** | זניח |
| יחסי `place=suburb\|neighbourhood` בירושלים | קיימים (נדגמו 5) | יש פוליגונים שאפשר להשתמש בהם |

**החלטה 4:** השיוך ייעשה ב-**point-in-polygon** של מרכז הרחוב מול פוליגוני השכונות.
רחוב שלא נופל באף פוליגון יסומן `area: "לא משויך"` — ולא ינוחש שם שכונה.

## צורת הנתונים

```json
{
  "id": "yafo",
  "name": "רחוב יפו",
  "area": "מרכז העיר",
  "lat": 31.78,
  "lng": 35.21,
  "path": [[31.78, 35.21], [31.79, 35.22]]
}
```

- `id` — יציב לנצח, כי הוא המפתח ב-`localStorage` של המשתמש.
- `lat`/`lng` — מרכז הרחוב (ממוצע משוקלל של מקטעים), לנקודה במפה.
- `path` — אופציונלי; קו לציור הרחוב. בלעדיו המפה מציירת נקודה.

**החלטה 5:** נקודה היא חובה, קו הוא בונוס. אף רחוב לא מוצג על המפה בלי `lat`/`lng`.

## מיזוג עם 75 רחובות הזרע — הכלל

1. מנרמלים שם: מסירים ניקוד, גרשיים, וקידומת `רחוב/דרך/שדרות/מדרחוב/סמטת/כיכר`.
2. מחפשים התאמה מדויקת ברשימת OSM.
3. **נמצאה** → הרחוב מקבל `lat`/`lng` אבל **שומר על ה-`id` הישן**. הביקורים לא הולכים לאיבוד.
4. **לא נמצאה** → הרחוב נשאר ברשימה, מסומן "אין מיקום", ולא מוצג על המפה.
5. רחובות חדשים מ-OSM מקבלים `id` חדש וצפוי (למשל `osm-<wayId>`), ולעולם לא מתנגשים במזהה קיים.

## גוגל מפות — מה שבאמת עובד בלי מפתח

קישור ישיר, ללא API, ללא עלות, ללא מכסה:

```
https://www.google.com/maps/search/?api=1&query=<שם הרחוב>, ירושלים
```

ואם יש קואורדינטות:

```
https://www.google.com/maps/search/?api=1&query=<lat>,<lng>
```

**החלטה 6:** זו הדרך המוגדרת כברירת מחדל. Places/Geocoding API רק אם יסופק מפתח במפורש — ואז יש עלות ומכסה.

## מה עדיין פתוח

- מספר הרחובות הייחודיים אחרי מיזוג מקטעים (9,828 מקטעים ≠ 9,828 רחובות).
- כמה מ-75 רחובות הזרע נמצאים ב-OSM לפי שם.
- כמה פוליגוני שכונות יש בפועל, ומה אחוז הרחובות שנופלים בהם.
