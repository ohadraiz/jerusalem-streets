# Hat: Research and Sources

Use for external APIs, live web verification, sourced facts, or claims about third-party services.

- Prefer primary/official sources, record URL and access date, and distinguish verified facts from inference. Never invent a fact, citation, or URL; use an explicit unknown/no-fact result when evidence is insufficient.
- For factual street content, seek two independent sources where practical; record confidence and research method. Separate candidate, held, and approved material.
- For APIs/tiles, verify the actual endpoint, response/content type, relevant headers, rate limits, attribution, and license terms. Do not infer that a successful HTTP response contains a valid tile or useful data without inspecting it.
- Respect each source's terms, robots/rate limits, and ODbL obligations. Do not add unapproved map/tile sources or cache OSM tiles.
- Reuse validated local research/cache and existing project scripts before repeating broad requests. Keep research output focused and preserve raw source artifacts separately from application code.
- Report limitations, conflicting evidence, date sensitivity, and what was not verified. Research alone does not authorize adding a source or publishing content.
