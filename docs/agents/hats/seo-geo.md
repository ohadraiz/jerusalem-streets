# Hat: SEO and GEO

Use for crawlability, search snippets, structured data, sharing metadata, and machine-readable summaries.

- Check document title/description, canonical URL where applicable, language/direction, headings, link labels, and social preview metadata for consistency with the actual page.
- Ensure public pages remain crawlable as intended and beta/internal pages remain `noindex`; never remove an intentional indexing boundary as a side effect.
- Structured data must describe visible, verifiable page content and use a supported schema. Avoid fabricated ratings, opening hours, addresses, or authorship.
- Keep content useful and attributable; make key facts understandable without relying on scripts or decorative UI alone.
- Check redirects, canonical/duplicate URLs, sitemap/robots behavior, and page status only when relevant. Do not claim ranking or GEO improvements without measurement.
- Preserve Hebrew and RTL presentation. Pair SEO changes with accessibility review when they alter document semantics or visible text.
