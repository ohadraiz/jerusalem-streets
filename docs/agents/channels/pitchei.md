# פתחי — ערוץ סביבת הפיתוח (בטא)

הערוץ האישי של פתחי, אחראי סביבת הפיתוח. רק פתחי כותב כאן; הסוכן הראשי קורא ומעביר.
זהו יומן שינויי הבטא והאישורים — לא יומן פיתוח כללי.

## כללי הסביבה

- **כל שינוי** בכל צוות מוצג קודם ב-`beta.html` (או ב-localhost) — לא באתר הציבורי.
- **אין פרסום בלי אישור מפורש של המשתמש.** אישור של סוכן אחר או שתיקה אינם אישור.
- `beta.html` נוצר מ-`index.html`; אין לערוך אותו ביד:
  `node tools/make-beta.js`
- אחסון בטא נפרד: `jlm-street-journal-beta-v1`. האתר הציבורי: `jlm-street-journal-v1`.
- `assets/` משותפים לשני העמודים. שינוי התנהגות חייב לעלות מאחורי דגל
  (`window.JLM_BETA` / `html.is-beta`) עד לאישור, ואז להתכבות.

## איך מגישים שינוי לפתחי

```
מגיש: <שם הסוכן/הצוות>
שינוי: <משפט אחד>
למה: <הבעיה שהשינוי פותר>

פתחי מחזיר: מה נבדק, תוצאות שערים, קישור לבדיקה, ומה ממתין לאישור.

## בקשה לאישור — תבנית

```
מוכן לבדיקה: <שם השינוי>
מה השתנה: <שתי שורות>
איפה לבדוק: <קישור ל-beta / הוראות>

המתנה לאישור מפורש. עם קבלת "מאושר" — סגירת הדגל, שערים חוזרים, פרסום, אימות חי,
ורישום כאן.

## יומן

### פתחי → ראשי · הקמת סביבת הבטא · 2026-10-22

**מה נבנה**
- `beta.html` — עותק מלא של האפליקציה, נוצר אוטומטית מ-`index.html`
  (`node tools/make-beta.js`, עם `--check` ו-`--source`). מסומן `noindex`, בלי מניפסט,
  מפעיל `window.JLM_BETA = true` ו-`html.is-beta`.
- `assets/beta-tools.js` — פאנל צף: תצוגת מכשיר (390×844, 430×932, 820×1180 בחלון נפרד),
  25 ביקורים לדוגמה, איפוס נתוני בטא, ייצוא/ייבוא JSON, מונה ביקורים ומפתח אחסון,
  קישור לאתר הציבורי. `Alt+B` פותח/סוגר, `?device=1` מסתיר את הפאנל.
- `assets/store.js` — מפתח נפרד לסביבת הבטא (`jlm-street-journal-beta-v1`).
- `assets/sw-register.js` — אין רישום Service Worker בבטא, כדי שכל בדיקה תיטען מהרשת.

**אימות שבוצע**
- תצוגת בטא: הפאנל והתג נטענים, הכותרת "סביבת בטא", אין `<link rel="manifest">`.
- סימון רחוב בבטא נשמר רק במפתח הבטא; המפתח האמיתי נשאר `null`.
- איפוס בטא מחזיר ל-0 ביקורים; 25 הביקורים לדוגמה נשמרים במפתח הבטא בלבד.
- `index.html` הציבורי: המפתח האמיתי, בלי פאנל בטא, ובלי כתיבה למפתח הבטא.
- שערים: `store` 24/24, `verify` 46/46, smoke 84/84, `node --check` נקי.

**הערה תפעולית:** `beta.html` נבנה מגרסת `index.html` של הקומיט הנוכחי, כדי שהעמוד
החי יתאים לקבצי ה-`assets/` שפורסמו. פיתוח מקומי מריץ `node tools/make-beta.js`
ומקבל את גרסת עץ העבודה.
