# Archived Agent-System History

This directory is not automatically loaded. It is an index for historical records retained for compatibility and future lookup.

- Decision history: `../BOARD.md`
- Task and handoff history: `../TASKS.md`
- Lessons learned: `../LESSONS.md`
- Historical role discussions and work logs: `../channels/` and `../teams/`
- Prior subagent-routing decisions: `../../../SUBAGENT_DECISION_FRAMEWORK.md` (the file is now the short current routing policy; older details remain in version history)

These records are historical, not current agent definitions or mandatory workflows. Do not load them automatically or treat old role assignments as active routing. Existing dashboard/data scripts still consume some legacy records; keep their source paths intact unless those compatibility tools are separately retired.
