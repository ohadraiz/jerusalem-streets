# רחובות ירושלים — יומן ביקורים

גרסה באנגלית: [README.en.md](README.en.md)

אפליקציית דפדפן קטנה (ללא תלויות, ללא build) שמאפשרת לסמן כל רחוב בירושלים שבו הייתם, עם תאריך והערה, ולראות התקדמות לפי שכונה.

## הרצה

**פשוט לפתוח `app.html` בדפדפן** — היומן עובד ישירות מהקובץ, בלי התקנה, בלי build ובלי שרת. כל הספריות מקומיות (`assets/vendor/leaflet`), והמפה עובדת גם מ-`file://` (עם OSM DE כספק אריחים, כי OSM חוסם בקשות ללא Referer).

```bash
npm start          # http://localhost:8787 — שרת מקומי, לפיתוח ולבדיקות בלבד
npm test           # בדיקות שכבת האחסון
```

השרת המקומי אינו חובה: הוא נוח לפיתוח, לבדיקת הנתיב `http://` (שם OSM הוא הספק הראשי) ולהכנה להעלאה לרשת. על `file://` חלק מהדפדפנים (למשל Safari) מגבילים `localStorage` — האפליקציה מזהה את זה ומציגה הודעה במקום להתפשר.

## העלאה לרשת

**האתר כבר עלה:** `https://ohadraiz.github.io/jerusalem-streets/` (GitHub Pages, ענף `main`). כתובת השורש מציגה את דף הבית (`welcome.html`); היומן עצמו נמצא בכתובת קבועה: `https://ohadraiz.github.io/jerusalem-streets/app.html`.

זהו אתר סטטי: **אין build ואין תלויות** — מעלים את התיקייה כולה למארח סטטי עם HTTPS ומקבלים כתובת, בלי פקודות.
מדריך מלא (אפשרויות אירוש, כותרות HTTP חובה, CSP, PWA ומטמון): [`docs/agents/teams/online-deployment.md`](docs/agents/teams/online-deployment.md).

כשהאפליקציה מותקנת (PWA) היא נפתחת **גם בלי חיבור לאינטרנט** — אחרי ביקור אחד הרשימה, הסימונים והמפה נשמרים מקומית; רק אריחי הרקע דורשים חיבור.

## סביבת בטא (לפני פרסום)

כל שינוי נבדק קודם ב-**beta** ולא באתר הציבורי: `https://ohadraiz.github.io/jerusalem-streets/beta.html`

- `beta.html` נוצר אוטומטית מ-`app.html`: `node tools/make-beta.js` (ולפני פרסום: `--check`). אין לערוך אותו ביד.
- נתוני הבטא נשמרים במפתח נפרד (`jlm-street-journal-beta-v1`) ואינם נוגעים ביומן האמיתי.
- פאנל הכלים: תצוגת מכשיר (390/430/820), 25 ביקורים לדוגמה, איפוס, ייצוא/ייבוא JSON.
- שינוי גדול נבדק ב-beta בעותק מבודד של קובצי האפליקציה (`assets/beta/`), בעוד האתר הציבורי ממשיך לטעון את `assets/*` — עד אישור מפורש של המשתמש. התהליך מתועד ב-[`docs/agents/HATS.md`](docs/agents/HATS.md) (כובע `testing-beta`).

## מה יש בו

- 75 רחובות זרע לפי שכונה (`assets/data.js`) — רשימה חלקית, ניתנת להרחבה.
- סימון ביקור בלחיצה אחת, עם תאריך (ברירת מחדל: היום) והערה חופשית.
- חיפוש בעברית שמתעלם מניקוד ומגרשיים, סינון לפי שכונה ולפי סטטוס.
- סטטיסטיקות: סה״כ, ביקרתי, נשאר, אחוז השלמה, ופילוח לפי שכונה.
- הוספת רחוב שאינו ברשימה.
- ייצוא/ייבוא JSON, ואיפוס.
- עברית ו-RTL, מצב כהה/בהיר, ניווט מקלדת, `aria-live` לכל פעולה.

## מודל הנתונים

נשמר ב-`localStorage` תחת `jlm-street-journal-v1`:

```json
{
  "schema": 1,
  "visited": { "yafo": { "date": "2026-10-21", "note": "קפה" } },
  "custom": [{ "id": "custom-...", "name": "רחוב חדש", "area": "שכונה" }]
}
```

עקרונות:

- **המזהה הוא החוזה.** `id` של רחוב לא משתנה לעולם, כי הוא מה שנשמר אצל המשתמש. שינוי שם תצוגה בטוח; שינוי `id` מאבד את היסטוריית הביקורים.
- כל קלט (מקומי או מיובא) עובר `sanitize`: אורכים מוגבלים, תאריך בפורמט `YYYY-MM-DD`, מזהים כפולים נדחים.
- נתונים פגומים **לא** נדרסים: הטעינה מחזירה `corrupt`, נשמר עותק תחת `jlm-street-journal-v1:corrupt:<timestamp>`, והמשתמש רואה באנר אזהרה.
- ייבוא דוחה קובץ שאינו גיבוי של היומן (בלי `visited`/`custom`, או ריק), כדי לא למחוק נתונים בטעות.

## תהליך העבודה עם הסוכנים

| סוכן | תפקיד | גבולות |
|---|---|---|
| **אני (ראשי)** | מיישם, מתקן, מחזיר שאלות ומשימות להמשך | כותב קוד |
| **שיפו** (`shifu`) | סוקר את הקוד בכל שלב ומחזיר ממצאים לפי חומרה | קורא בלבד, לא עורך |
| **מפי** (`mappy`) | משלים את רשימת הרחובות לפי שכונה ומגדיר את החיבור למפות | חוקר בלבד, לא עורך |
| **צירי** (`tsiri`) | מתכנן את המפה האינטרקטיבית שמתעדכנת לפי הביקורים | מתכנן בלבד, כותב רק לערוץ שלו |
| **חיקי** (`chiki`) | חוקר באינטרנט מקורות נתונים, APIs ומאגרים ומאמת אותם בפועל | חוקר בלבד, כותב רק לערוץ שלו |
| **מובריליס** (`moverilis`) | אחראי המובייל וההפצה: מתעדף ומתאם בין שני ראשי הצוותים, מנהל סיכונים ומכין go/no-go | לא נוגע בקוד, לא מפרסם ולא מאשר תקציב |
| **מובי** (`mobi`) | ראש צוות המובייל: PWA, התקנה, מסך מלא, מגע, ליבה ללא רשת וביצועים | לא נוגע בנתונים, אחסון, מפה ועיצוב |
| **פיצי** (`pitzi`) | ראש צוות ההפצה: אחסון, HTTPS, כותרות, CI/CD, גרסאות וגלגול אחורה | לא נוגע בקוד האפליקציה |

הסוכנים לא מדברים ביניהם ישירות — הם מתכתבים דרך `docs/agents/BOARD.md` והערוצים
ב-`docs/agents/channels/`, ואני מעביר ביניהם ומחליט מה מיושם.

הלופ: שיפו סוקר → אני מתקן → שיפו סוקר שוב, עד שאין ממצאים חוסמים. במקביל מפי מביא נתונים ומפרט,
צירי מתכנן את המפה, ואני מיישם.

## מגבלות ידועות

- רשימת הרחובות חלקית (75 מתוך אלפים). השלמה מלאה ממתינה לפייפליין הנתונים של מפי.
- אין מפה ויזואלית ואין קישור לרחוב בגוגל מפות — מתוכנן.
- כל הנתונים מקומיים לדפדפן אחד; אין סנכרון בין מכשירים (אבל יש ייצוא/ייבוא).
