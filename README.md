# רחובות ירושלים — יומן הליכות בעיר

גרסה באנגלית: [README.en.md](README.en.md)

יומן הליכות חינמי בעברית וב־RTL: מסמנים את הרחובות בירושלים שבהם ביקרתם, מוסיפים תאריך, הערה ודירוג, ורואים את ההתקדמות לפי שכונה — ללא הרשמה וללא שרת.

## שימוש

**האתר החי:** [ohadraiz.github.io/jerusalem-streets](https://ohadraiz.github.io/jerusalem-streets/)

- [דף הבית](https://ohadraiz.github.io/jerusalem-streets/welcome.html)
- [היומן](https://ohadraiz.github.io/jerusalem-streets/app.html)

אפשר גם לפתוח את `app.html` ישירות בדפדפן. אין צורך בהתקנה, ב־build או בתלויות חיצוניות: ספריית Leaflet וכל קובצי האפליקציה נשמרים מקומית. שרת הפיתוח המקומי נדרש רק לפיתוח ולבדיקות:

```bash
npm start          # http://localhost:8787
npm test           # בדיקות שכבת האחסון
npm run verify     # בדיקות מבנה ושלמות
```

## מה יש באפליקציה

- מאגר של **2,424 רחובות ב־95 שכונות**, כולל קואורדינטות וגיאומטריה.
- חיפוש בעברית, סינון לפי שכונה ולפי סטטוס, ומיון רשימת הרחובות.
- סימון ביקור עם תאריך, הערה, דירוג של 1–5 ומצב רוח.
- מפה אינטראקטיבית שמציגה את הרחובות ומדגישה ביקורים; אפשר לפתוח רחוב ב־Google Maps.
- סטטיסטיקות, התקדמות לפי שכונה, הישגים והשלמה ידנית של שכונה.
- רחוב אקראי, הוספת רחוב מותאם אישית, מחיקה עם אפשרות ביטול וניווט בין עמודי הרשימה.
- ייצוא וייבוא JSON לגיבוי או להעברת היומן למכשיר אחר.
- מצב בהיר/כהה, חיווי קולי וצלילים/רטט, קיצורי מקלדת ותמיכה בקוראי מסך.
- מאגר כרטיסי «הידעת?» על רחובות ושכונות.
- PWA: לאחר ביקור ראשון, האפליקציה והנתונים זמינים גם ללא חיבור; אריחי הרקע של המפה דורשים רשת.

## נתוני הרחובות

המאגר נמצא ב־`assets/data.js` ומתעדכן מתוך נתוני OpenStreetMap ברישיון ODbL. הגרסה הנוכחית היא 3, עודכנה ב־21 באוקטובר 2026, ומבוססת על עותק Geofabrik מ־20 באוקטובר 2026. שכבת האריחים משתמשת ב־OpenStreetMap, OpenStreetMap DE או OpenTopoMap לפי זמינות.

## פרטיות וגיבוי

הביקורים נשמרים מקומית בדפדפן תחת `jlm-street-journal-v1`; אין חשבון ואין סנכרון בין מכשירים. השתמשו בייצוא JSON כדי לגבות או להעביר את היומן. נתוני בטא מבודדים תחת `jlm-street-journal-beta-v1`.

## סביבת בטא

כל שינוי נבדק תחילה בסביבת [beta](https://ohadraiz.github.io/jerusalem-streets/beta.html), ולא באתר הציבורי. `beta.html` נוצר אוטומטית מ־`app.html` ואין לערוך אותו ביד:

```bash
node tools/make-beta.js
node tools/make-beta.js --check
```

## ארכיטקטורת העבודה

- `build` הוא תפקיד המימוש הראשי ומבצע ישירות גם בדיקות, תיעוד ואינטגרציה.
- `review` הוא ביקורת עצמאית לקריאה בלבד, לפי scope מוגדר.
- `gabbai` מבצע פעולות release בלבד ורק לאחר אישור מפורש לפעולה הספציפית.
- מומחיות תחומית נטענת לפי צורך ככובעים מתוך `docs/agents/HATS.md`; הכובעים אינם סוכנים נוספים.
- מרכז ה-workflow ודשבורד המשימות הפנימיים נוצרים מהמקורות באמצעות `tools/guli-room.js` ו־`tools/tasks-dashboard.js`.

היסטוריית ההחלטות והמשימות נשמרת תחת `docs/agents/` לצורך עיון, אך אינה מגדירה ניתוב פעיל.

## מבנה הפרויקט

```
welcome.html          דף הבית וההסבר
app.html              היומן עצמו
assets/data.js        מאגר הרחובות
assets/app.js         לוגיקת היומן, החיפוש, הסינון והסטטיסטיקות
assets/map.js         המפה ושכבות האריחים
assets/store.js       אחסון, סניטציה, גיבוי וייבוא/ייצוא
assets/geo.js         גיאומטריית הרחובות
assets/dyk-facts.js   כרטיסי «הידעת?»
sw.js                 Service Worker ופעולה ללא רשת
tests/store.test.js   בדיקות שכבת האחסון
tools/verify.js       בדיקות הפרויקט
```
